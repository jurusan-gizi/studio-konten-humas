Kirim ke Humas

Ikuti langkah ini, lalu kirim lewat Formulir Permintaan Publikasi Informasi.

  1. Simpan gambar finalSemua slide disimpan ke folder Drive "Hasil" dan bisa diunduh ke perangkat.
    Buka folder
  2. Salin judul
  3. Salin captionKolom caption di formulir hanya satu baris, jadi paragraf otomatis digabung.
  4. Buka formulir dan isiTempel judul dan caption. Di kolom unggah, pilih Add file → My Drive lalu buka folder Studio Konten Humas → Hasil, atau pilih file yang sudah diunduh.
    Buka formulir Humas
  5. Tandai sudah terkirimStatus berubah menjadi "Terkirim ke Humas" dengan tanggal hari ini.
